## Fixed scope and order

1200 seconds inclusive,1215 outer timeout; stdlib CPU only,8GiB memory, no install,
HTTP, Docker, GPU, RGB, FIT or selection. No retries, substitutions or alternate
URLs. Historical432 slots—including unavailable photos—are excluded using only
their original publisher identity ledgers. Known MD5/author exclusions are counted;
new bytes/creators remain unknown, so author independence is **not** certified.
Old reference paths/values, prediction banks and pixels are never opened.

1. Stream both original2014 instance members' images/licenses/categories while
   lexically skipping all annotation values. Require original native filenames,
   image URLs, CC-BY2 license4 and category1 person. This is a publisher recorded
   photo grant, not independent creator authentication. Reject historical photos
   before annotation semantics; duplicate fresh photo aliases do not increase
   capacity. Split IDs are structural, unique, and validate train/val/trainval/test
   unions and disjointness. No role semantics are consulted for train/trainval.
2. Stream the same two CRC-complete members again. Decode annotation rows only
   for rights-eligible, nonhistorical official VAL/TEST image IDs. Retain original
   annotation IDs, all persons/objects, raw XYWH/area/crowd; no clipping or repair.
3. Two-pass action-major projection reads structural agent/image vectors first,
   and then label/role IDs only for eligible images, independent of field order.
   The pure reference join preserves original row/role slots. Positive missing
   role0 is UNKNOWN, never OFF. Self/person/crowd/invalid geometry roles remain
   unscorable diagnostics, not negatives. Same physical positive pair has one
   primary weight while every original action/role provenance is retained.

Count capacity separately in official VAL and TEST. An eligible image has at
least2 finite positive-area noncrowd persons,2 such nonperson objects, and1
localized positive nonperson role pair. Raw off-grid boxes stay unchanged and
eligible if finite and positive, not silently clipped. Count images with≥2
positive agents separately; that is **diagnostic only**, not a hidden extra gate.
The fixed capacity gate is≥8 distinct photos in each split. No action vocabulary,
contact/ownership predicate, hand side or target prompt is inferred. All general
localized positive roles are included; this is not manipulation/contact truth.

The output is one sealed0400 report under0500 fresh metadata namespace, with
counts, complete stream hashes, source/input identities and an opaque eligibility
inventory digest only. No fresh reference values, eligible-ID list or cohort is
exported. Source/input bytes and modes are rechecked before publication; late
deadline/source/seal failures cannot leave a PASS receipt. Insufficient capacity
closes without RGB or resampling. Success establishes metadata capacity only,
not endpoint recall, relation accuracy, official V-COCO AP, anatomical ownership,
temporal identity, Track1 target accuracy, CARI4D victory or submission eligibility.
V-COCO/COCO model pretraining overlap and repo-wide MIT scope ambiguity remain
disclosed; underlying photo CC-BY2 is distinct from role annotation permissions.

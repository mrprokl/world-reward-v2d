## Acquire frozen slots only

Separate `acquire` phase requires explicit sealed selection report/cohort pins;
reference files are hashed only, never decoded. Each slot requests its original
publisher S3 HTTPS COCO2014 JPEG once, using the recorded native partition and
filename. This is an explicit transport-only HTTPS upgrade of original COCO
publisher metadata, no Flickr fallback, alternate image, resizing/cropping or
EXIF repair.15 s request,4 workers,16 MiB/image,16M pixels,256 MiB total,
300 s inclusive/315 cleanup. Failures retain all16 ledger slots; no retries.
Historical-byte MD5 aliases are rejected, and all copies of a duplicate within
the new16 cohort become unavailable. JPEG grid/header qualification is not full
decode or visual quality evidence.

Public `world_reward.rgb_proposal_inputs.v1` has acquired-only six-key records:
opaque image ID, original `image_<slot:06d>.jpg`, bytes, SHA256, width, height.
No role, split, count, category, reference, creator or target metadata crosses
that boundary. All16 missing/acquired records and attribution stay private.
Availability gate ≥6 acquired DEV and≥6 RESERVED; future metric denominators
remain8/8, unavailable slots score missing, never resampled. Failure closes before
model inference/FIT. Selection/acquisition directories500/files400; root-private
namespace700, original inode/provenance and same-FD late-PASS demotion required.
Both units use the **same frozen published revision/entry**; acquisition is not
a new source variant. Invocation is `select`, then separately
`acquire <report_bytes> <report_sha256> <cohort_bytes> <cohort_sha256>`.
`inputs/manifest.json` plus acquired JPEGs is the only model-facing namespace;
`eval_private/report.json` preserves all16 slots, source bindings, private
attribution, public mapping and missing reasons. It never supplies predictions.

Publisher CC-BY2 photograph metadata is accepted **for this private pilot**,
with attribution retained, not independent creator authentication or submission
clearance. V-COCO repository-wide MIT private research interpretation and notices
are inherited from the original metadata receipt. Model pretraining/challenge
overlap remains UNKNOWN, never leakage-free. Eventual evaluation is positive
person-object role retrieval only: missing roles/unannotated alternatives are
not OFF/negative/contact/anatomical-hand ownership/task-target ground truth.

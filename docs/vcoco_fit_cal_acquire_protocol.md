## One bounded original request per slot

One HTTPS request to the original COCO S3 JPEG per selected slot, no live Flickr
request. Reuse the unchanged original fetch helper: proxies disabled, redirects
rejected, no cookies/authentication or retries. Four workers, each request at most
15 seconds, total HTTP window at most 300 seconds within the 1200-second inclusive
budget. Maximum 16MiB/JPEG, 16M pixels by JPEG header, 768MiB total (48x16MiB).
Only original bytes and their header/MD5/SHA are examined: no pixel decode or model.

Every unavailable slot stays in the fixed denominator. Any historical MD5 alias,
missing image, header mismatch, expiry or duplicate new MD5 prevents qualification.
Duplicate new files are retained as evidence, never used to filter/reduce/reseed a
training set. **ALL48 acquired and unique are required**; there is no smaller-FIT or
smaller-CAL rescue. CAL is not a tuning set or independent final-test claim.

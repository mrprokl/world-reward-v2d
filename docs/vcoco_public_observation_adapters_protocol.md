# Public48 anatomy/HOI adapters — source-only

Two small modules, no caller/job/model/transport or executed48 inference. No
future PASS or pin is manufactured; old qualified numerical code is unchanged.

## Two explicit boundaries

**Host only:** `authenticate_endpoint(context, code, current_source,
endpoint_source, report_pin, deadline)` verifies the independently pinned old
complete48 host/native/proof chain and reopens all17 endpoint arrays. The caller
first authenticates both whole Git closures and runtime/model lineage. Helper
origin checks are not whole-Git verification. This returns only four keys:
`schema`, six-field public `inputs`, `manifest_identity`, and48 `banks` with the
fixed16 public metadata keys/full17-array identities. Old receipts, source
bindings, acquisition/private paths, grants, splits and model assets are absent.

**Native only:** the caller writes and pins this projection in its new public
proof, then calls `public_bank_reference(context, projection_path,
projection_pin, code, native_source, deadline, native_mounts=True)`.
`native_source` is exactly a `helpers` dictionary of the current native whitelist,
not a host/source/acquisition proof. The frozen reference contains immutable
bytes; no stored deadline. Every operation takes the caller's explicit deadline.
Native sees49 original RGB leaves (manifest plus48 JPEGs),48 endpoint NPZ leaves,
the newly pinned public projection and current code. **Never mount the original
endpoint host report/proof/qualification namespace.** Individual Docker leaf
remapping produces an exclusive48-NPZ directory, without copying data or making
hardlinks. Synthetic bind-parent modes/inodes are observed locally, not inferred
from host parents; all leaf hashes and original IDs remain unchanged.

`PublicObservationContext(inputs, endpoint_banks, output)` requires separate,
canonical nonsymlink namespaces. The native factory and adapters verify every
JPEG and full17 bank before the first forward; post/failure verification is not
another model call. Exact original frame0/grid/slots0..47 never become smaller
ordinals. Public data returns are copies of immutable stored bytes.

## Existing math through callbacks

`observe_pose(reference, original_observe, infer, deadline, records=...)`
delegates unchanged cardinality-generic `vcoco_person_pose_observations.observe`.
The caller supplies qualified `infer(rgb, ids, boxes, scores)` using one original
session. All retained people and133 points survive; P0 gives genuine empty arrays
without upstream full-image fallback. Saved retained boxes/detector scores stay
original float64 (raw GDI postprocessor arrays are float32); decoded XY is
float64, raw joint scores float32, score>0 validity and in-grid flags distinct.
Eleven arrays preserve the original ABI without anatomy filling or selection.

`observe_hoi(reference, infer, deadline, records=...)` adds only the fixed48 loop
around unchanged `infer_hoi_detr_frame`. Model construction,1796 strict states,
BGR/preprocessing,1500 native queries/postprocessing and every Cartesian H→O/O→T
pair remain caller-owned and unchanged. K0 is valid; no K cap or OWL3600 deletion.
Nineteen arrays preserve original logits, native IDs and duplicate class routes.

Both adapters save exclusive x/fsync/400 imagewise NPZ and reopen every member
for exact dtype/shape/byte identity. Completed rows remain visible on failure;
`validate_saved_records(complete=True)` requires48. Partial integrity cannot
claim success. Caller owns source/model qualification, callbacks' origins,
output sealing, memory/deadline, process/session cleanup and honest receipts.

# Explicit-context V-COCO full48 endpoint observation seam

This is a **source-only adapter**, not a dispatched native job, model/runtime
qualification, FIT/CAL evaluation, endpoint-capacity result or ownership claim.
It does not launch containers, load models, read private acquisition metadata,
install packages, download anything, or perform selection/association.

## Exact reusable numerical path

`EndpointContext(inputs, output)` supplies separate canonical nonsymlink paths.
`public_inputs(context, independent_manifest_pin)` authenticates exactly48 six-key
opaque RGB rows, original slots0..47, with no holes or smaller-population rescue.
The filename is **manifest.json**, not public_inputs.json. Public rows contain
only image_id/file/bytes/sha256/width/height; no native ID, split, role or label.
Native individual mounts may have synthetic writable directory modes but every
original file remains read-only and byte-pinned.

`source_identity(code, whole_caller_source)` checks current helper origins and
frozen byte identities. It does not authenticate arbitrary producer Git commits
or substitute for the caller's full source/runtime/asset proof. The original
`rgb_endpoint_bank.load_models(policy)` loads one GDI and one OWL model; the caller
passes its original returned tuple to `observe(context, inputs, models, deadline)`.
No old native()/dispatch(), DATA/OUTPUT mutation or profile monkeypatch exists.

The unchanged original `bank_arrays` and `save_bank` are reused. Every image has
one fixed `person.` call, .3 confidence/.25 text threshold, original .7 NMS and
all raw900 query boxes/256-token logits including native masked -inf. Retained
person IDs/slots remain in original order; P=0 is valid with no fallback.
OWL keeps all3600 patch IDs, FP32 raw objectness, padded normalized CXCYWH and the
original square-pad inverse XYXY, including outside-image coordinates. No topK,
crop, truncation, clipping or learned person/owner confidence is introduced.

## Returned/saved evidence

The original17 arrays and shape/dtype/byte-SHA records are validated before save;
native token-padding and post-NMS mappings are replayed solely as integrity checks.
Each original NPZ is saved once with x/fsync/read-only publication. Original
slots and acquired ordinals are identical0..47; frame index is0 per still image.
`validate_records` reopens every complete saved bank with allow_pickle=False,
revalidates all17 arrays and mappings, and authenticates each original output pin.
This is not another forward pass or a numerical quality comparison.

All48 input JPEG byte hashes are checked before the first forward and in finally.
Caller-owned incremental records preserve completed rows if a later inference,
save or deadline fails. A partial list never satisfies full48 validation. The
adapter neither synthesizes missing banks nor retries/resamples. Models and GPU
buffers remain caller-owned and must be released by the caller on every exit.

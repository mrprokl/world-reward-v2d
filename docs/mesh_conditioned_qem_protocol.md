## Algorithm boundary

midpoint `o` and the smallest representable positive power-of-two covering
extent `L`. Freeze it before QSlim. Native execution requires numerical-exact
F64 roundtrip of **every source vertex**, including orphans. Byte equality and
signed zero are separately diagnosed. Reject overflow/underflow or loss; never
snap, remove a shell, repair or optimize physical scale.

QSlim quadrics, placements and its floating-point intersection guard operate in
this chart. Because the point prior is now dimensionless, this is explicitly a
**new numerical algorithm**, not unchanged native physical cost. No SVD/robust
solver has been added. Reuse the exact original volume and serialization core
byte prefixes, without modifying their sources. Both physical guards see the
same inverse `o+L*x'` (separate multiply/add, no FMA) used after each collapse
and in output. Native full `I/J` remain unchanged. The original volume formatter
is reused; only its two now-inapplicable cost metadata flags are replaced.

Physical source shell volumes, the fixed ±5% band, F32 exact triangle orientation
and global default-eight-digit collision keys remain in the original physical
frame. Native canonical intersections alone do not prove that rounded physical
output is embedded: independent physical and serialized checks are mandatory.
Below-budget safe identity exports original physical values without decoding.
